# Greed Machine narration

60-second concept film, using the builder's saved KittenTTS 2 voice. The builder chose **voice only** and will render/export from localhost. These lines describe intended mechanics; the 60–70% holder share is a target range and final economics remain to be set.

| Time | Narration |
| --- | --- |
| 0.4–8.3s | Greed Machine is a memecoin with mechanics: buy, hold, and participate in an autonomous treasury business. |
| 9.1–17.3s | Launch proceeds and project trading fees would fund the treasury. Retained earnings help the business keep growing. |
| 18.1–26.3s | An AI swarm scouts opportunities, proposes strategies, and debates them. Agents challenge assumptions before choosing a candidate. |
| 27.1–35.3s | Independent security reviews the candidate. Hard rules cap spending, protect reserves, and can reject every proposal. |
| 36.1–44.3s | Only approved strategies receive capital. The machine would monitor positions, manage exits, and reconcile costs and losses. |
| 45.1–53.8s | Target: sixty percent to seventy percent of eligible net profit, shared with holders in stablecoins. The rest grows the treasury. |
| 54.0–59.6s | Buy. Hold. Inspect. A memecoin designed to do business. |
