# Greed Machine visual system

The user requested a replacement for the blue palette on October 25, 2026. The site uses warm ivory, charcoal and olive, with amber highlights. The layout, typography, illustration geometry and interactions retain the existing product identity.

| Role | Value | Use |
| --- | --- | --- |
| Brand/action | `#3f5138` | Landing hero, treasury panel, primary actions, active navigation |
| Canvas | `#f3efe5` | Main page background and pale foreground on dark regions |
| Ink | `#262820` | Main text |
| Accent | `#cda45c` | Retained treasury share, illustration traffic, selection and focus on the hero |
| Elevated surface | `#faf8f2` | Forms and distribution records |
| Secondary text | `#66685b` | Reading hierarchy on light surfaces |
| Separator | `#d7d5c8` | Tables and section boundaries |
| Success surface/ink | `#e1e7d4` / `#3a5134` | Verified, reconciled and accepted states |
| Error surface/ink | `#f6dfe0` / `#962f3c` | Failure and recovery states |

Use olive for actions and wayfinding; amber carries the profit split and selected concept phase. Semantic states always include labels or icons. Keep numerical financial evidence legible on warm, quiet surfaces. The Three.js scene and its reduced-motion fallback use the same ivory, olive and amber family.

Geist is the existing self-hosted interface face; Geist Mono is reserved for hashes, code and raw units. Motion preferences, pause controls, keyboard navigation and the operator/public boundary remain part of the design.

The legacy CSS token `--blue` now resolves to the olive brand color. Related pale surfaces and hover colors are mapped to the new palette rather than retaining blue tints.
