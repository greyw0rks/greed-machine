## Description ready to review

Greed Machine makes an agent-run token treasury inspectable. Its intended holder experience is buy, hold and receive eligible stablecoin profit distributions. The prototype separates competing strategy proposals, independent security review, deterministic spending limits and settlement records. NEAR contracts enforce capped treasury actions, protected reserves and restricted operator permissions. A completed public NEAR testnet rehearsal demonstrates funding, an operating expense, a controlled vault cycle, frozen holder entitlements, failed-recipient recovery and replay-safe test-token payouts. Saved evidence reconciles 1,004.55 gUSD in the treasury, 8.45 gUSD paid and no unpaid liabilities. The web app also provides reproducible simulations and public activity records. gUSD is unbacked and vault returns are sponsor-funded fixtures; launchpad fee routing, live DeFi strategies and production stablecoin payouts are future work. Model agents never receive treasury keys. The public repository contains setup instructions, tests, contract evidence and the concept video.
